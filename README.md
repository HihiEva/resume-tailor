# resume-tailor

用于 LaTeX 简历定制的 AI skill：根据 JD 推荐经历，分层确认实习、项目及具体条目，再改写为有事实依据的量化内容，并检查一页满行排版。可按需准备求职邮件草稿及网申内容。

## 主要规则

- 默认只修改实习经历和项目经历，教育、荣誉、技能及全局模板保持原样
- 先确认所选经历及条目，局部改写无需重选整份简历
- 从真实材料中核对贡献和数字，不编造成果
- 新增或改写的条目末尾不加中文或英文句号
- 默认一页，尽量满行，以最新编译的实际 PDF 为准
- 未采用内容逐行注释保留，不删除原文
- 邮件只保存草稿，文档类附件使用 PDF；网申以使用者自己的完整履历为准

## 安装到 Codex

将整个仓库放到 Codex 的 skills 目录下，文件夹名为 `resume-tailor`。默认路径是 `~/.codex/skills/resume-tailor`；自定义了 `CODEX_HOME` 时使用该目录下的 `skills/resume-tailor`。

默认配置可执行：

```bash
git clone https://github.com/HihiEva/resume-tailor.git ~/.codex/skills/resume-tailor
```

目标目录已存在时先检查已有版本，避免覆盖自己的配置。也可以下载 ZIP，解压后将包含 `SKILL.md` 的文件夹命名为 `resume-tailor`，放入上述位置。安装后重新打开会话以便发现 skill。

其他支持 `SKILL.md` 的 AI 工具可按其 skills 目录规范安装；`agents/openai.yaml` 是 Codex 的界面元数据，其他工具可忽略。

## 使用

提供当前 `.tex` 主文件、目标 JD，以及能证明本人贡献与数字的项目材料，然后调用：

```text
使用 $resume-tailor，根据这份 JD 调整我的简历
先让我选择实习、项目及其具体条目，确认后再修改
```

局部改写时可以直接指定条目；需要邮件或网申时另行说明，并提供本人的发件账号、材料目录、作品链接或完整履历。

## 环境与文件

仓库只包含规则和使用说明，没有执行脚本或 Python 依赖。编译与视觉检查需要使用者自己的 LaTeX 环境、项目字体、模板依赖及 PDF 预览能力。没有编译或预览工具时，skill 会说明未验证的部分。

本仓库不附带简历模板、个人简历、证书或报告。请自行提供 `.tex` 及其引用的 `.cls`、`.sty`、图片等文件；邮件和网页操作还需要使用者环境中可用并已授权的对应工具。

```text
resume-tailor/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── README.md
```

这是可分享的通用版本，邮箱、路径、学校、单位、项目、奖项及作品链接均由当前使用者提供。
